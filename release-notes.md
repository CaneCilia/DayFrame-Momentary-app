Base-Application-Model

DayFrame V1.1 - Cloud and Backup Phase Complete

This pre-release establishes the Base Application Model for DayFrame, finalizing all local-first architecture and introducing cloud synchronization. 

Features included:
- Local-first photo capture and timeline storage
- SQLite database initialization and local data layer
- Authentication system with email and password integration
- Google Drive native backup integration via REST API
- Storage and Data management screen to clear cache
- Privacy Hub with local architecture details and account deletion request
- Cloud Sync Status indicator UI

This serves as the foundational model before transitioning into V2 feature development.
