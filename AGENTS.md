# Workflow Rules
- **Commit Every Process:** For the initial stage, every time a new page, function, or file is created, it must be committed immediately.
- **Push to GitHub:** Commit each process and push it to GitHub.
- **Commit Categories:** Prefix commit messages with one of the following tags depending on the task:
  - `[Feature]`
  - `[Bug]`
  - `[Update]`
  - `[Refinement]`
  - `[Issue]`
